The most common loop written in Linear is some variant this one (Issue > Agent > PR > Release) 

~30% of our bugs make it all the way through this flow.

But there are some nuances to doing it -- The instructions should ask the agent to extensively research the root cause of the issue and to use Datadog and Sentry MCPs to gather more evidence.
